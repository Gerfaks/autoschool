# Autoschool

Небольшой веб-сервис для автошколы на Flask. Проект разделен на три роли:
администратор, инструктор и курсант.

Администратор ведет учеников, инструкторов, машины, площадки, занятия, заявки и
оплаты. Инструктор видит свое расписание и данные по машине. Курсант может
смотреть личный кабинет и записываться на занятия.

## Соответствие лабораторной 4

### 8 баллов
- CRUD курсов: раздел администратора `/admin/courses`.
- CRUD заданий, дедлайны и назначение курсов курсантам: карточка курса в
  разделе `/admin/courses`.
- Фильтрация заданий по статусу и сортировка по дедлайну: раздел курсанта
  `/student/courses`.
- Личные статусы заданий курсанта: `Не начато`, `В процессе`, `Завершено`.
  Статус хранится отдельно для каждого курсанта и не меняется у других.
- Авторизация и роли уже реализованы: администратор, инструктор, курсант.
- Все данные хранятся в PostgreSQL через SQLAlchemy.

### 9 баллов
- Курсант может выгрузить свои задания по назначенным курсам в `docx` и `xlsx`
  из раздела `/student/courses`.
- Администратор может выгрузить отчет по заданиям с истекшим сроком выполнения в
  `docx` и `xlsx` из раздела `/admin/courses`.
- В разделе курсанта есть визуальная подсветка дедлайнов: выполнено, скоро,
  срок истек, без дедлайна.
- Добавлен скрипт наполнения базы, чтобы быстро показать курсы, задания,
  разные статусы и задания с истекшим сроком выполнения.
- Добавлен запуск через Docker Compose с PostgreSQL и веб-приложением.

## Соответствие лабораторной 5

- Раздел личных задач доступен по адресу `/todo`.
- Реализовано SPA-приложение: добавление, редактирование, удаление и завершение
  дел выполняются через JSON API без перезагрузки страницы.
- Есть счетчики общего количества, активных, завершенных дел и дел с истекшим сроком.
- Поддерживаются категории дел с CRUD-операциями.
- Дела и категории привязаны к авторизованному пользователю: каждый пользователь
  видит только свои записи.
- Дополнительные возможности для 10 баллов: поиск, фильтры по статусу,
  категории и приоритету, сроки выполнения, приоритеты и подсветка истекших сроков.

## Запуск у себя

Сначала заберите проект и перейдите в папку:

```bash
git clone https://github.com/Gerfaks/autoschool.git
cd autoschool
```

Дальше создайте виртуальное окружение и поставьте зависимости.

Для macOS / Linux:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Для Windows PowerShell:

```powershell
py -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## База данных

В PostgreSQL нужна пустая база:

```sql
CREATE DATABASE drivingschool;
```

После этого укажите строку подключения. Пароль, конечно, поставьте свой.

macOS / Linux:

```bash
export DATABASE_URL='postgresql://postgres:YOUR_PASSWORD@localhost:5432/drivingschool'
```

Windows PowerShell:

```powershell
$env:DATABASE_URL = "postgresql://postgres:YOUR_PASSWORD@localhost:5432/drivingschool"
```

Если переменную не задавать, приложение попробует подключиться к базе
`drivingschool` под пользователем `postgres` с паролем `postgres`.

## Первый запуск

Создайте таблицы и начальные данные:

```bash
python init_db.py
```

Скрипт создает таблицы, применяет миграцию схемы и добавляет администратора,
если его еще нет.

Данные администратора по умолчанию:

```text
Логин: admin
Пароль: admin123
```

Для проверки лабораторной можно сразу добавить готовые учебные данные:

```bash
python seed_data.py
```

Скрипт добавит учебные аккаунты, курсы, задания, личные задачи, категории задач,
автомобили, площадки, занятия, платежи, заявки, отмены и расписание инструкторов.

Данные для входа после наполнения базы:

```text
Администратор: admin / admin123
Инструктор: sergey.petrov / instructor123
Курсант: anna.smirnova / student123
Курсант: ivan.petrov / student123
Курсант: maria.sokolova / student123
Курсант: alexey.orlov / student123
```

Теперь можно запускать сайт:

```bash
python app.py
```

По умолчанию он открывается здесь:

```text
http://127.0.0.1:5001
```

Для остановки сервера нажмите `Ctrl + C` в терминале.

## Запуск через Docker

Если установлен Docker, проект можно поднять вместе с PostgreSQL одной командой:

```bash
docker compose up --build
```

Сайт будет доступен по адресу:

```text
http://127.0.0.1:5001
```

Чтобы добавить учебные данные в контейнерную базу, выполните в отдельном терминале:

```bash
docker compose exec web python seed_data.py
```
